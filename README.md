# Deep Learning Lab Assignments

This repository serves as a collection point for all assignments and code developed during the Deep Learning Lab course.

## Tentative Syllabus

The lab experiments may be adjusted based on course requirements. The current tentative syllabus includes:

1.  Familiarization with cloud-based computing like Google Colab and GPU Programming.
2.  Basic image processing operations: Histogram equalization, thresholding, edge detection, data augmentation, morphological operations.
3.  Implementation of SVM/Softmax classifier for CIFAR-10 dataset: (i) using KNN, (ii) using a 3-layer neural network.
4.  Study the effect of batch normalization and dropout in neural network classifiers.
5.  Familiarization with image labeling tools for object detection and segmentation.
6.  Image segmentation using Mask RCNN, UNet, SegNet.
7.  Object detection with single-stage and two-stage detectors (Yolo, SSD, FRCNN, etc.).
8.  Image Captioning with Vanilla RNNs.
9.  Image Captioning with LSTMs.
10. Network Visualization: Saliency maps, Class Visualization.
11. Generative Adversarial Networks.
12. Chatbot using bi-directional LSTMs.

## Lab Assignments Completed

### Lab 1: Introduction to PyTorch Tensors

This lab focused on the fundamentals of PyTorch tensors, covering their creation, properties (dimensions, data types, device), special tensor types (zeros, ones, random), data type manipulation, basic arithmetic and statistical operations, and tensor reshaping. The assignment is documented in `lab1/dl_01.ipynb`.

### Lab 2: Backpropagation and Neural Networks

This assignment involves implementing backpropagation for both logistic regression and a general neural network. It includes exercises to be solved based on the provided code. The goal is to get the backpropagation code running and then complete the exercises. The submission requires a PDF of the notebook.
